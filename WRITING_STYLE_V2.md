# ELYNDRAN — ESTÁNDAR DE ESCRITURA V2

## Objetivo

Reescribir y afinar la novela para que se sienta vivida desde dentro, no narrada desde fuera.

La voz canónica será **primera persona limitada**.

El lector solo sabe lo que yo veo, oigo, recuerdo, temo, deduzco o decido en ese momento.

## Regla principal

No escribir como informe de misión.

No enumerar datos porque existen.

Cada dato debe justificar su presencia por una de estas razones:

- peligro inmediato,
- decisión,
- emoción,
- descubrimiento,
- continuidad necesaria,
- misterio.

Si un dato no cambia nada, se recorta.

## Personalidad de la voz

La voz debe sonar humana.

El protagonista puede:

- tener miedo sin declararlo siempre,
- equivocarse,
- irritarse,
- hablar solo,
- recordar algo breve,
- usar ironía seca,
- tomar decisiones imperfectas,
- notar hambre, frío, dolor y cansancio,
- obsesionarse con detalles cuando está nervioso.

Evitar una voz excesivamente clínica, perfecta o explicativa.

## Ritmo

Alternar frases breves con párrafos más fluidos.

Las frases cortas deben usarse para:

- impacto,
- peligro,
- respiración,
- duda,
- descubrimiento.

No convertir todo el texto en listas de frases telegráficas.

## Datos técnicos

Mantener solo los imprescindibles.

Evitar cadenas largas de cifras, diagnósticos, materiales o mediciones salvo que sean relevantes para sobrevivir o entender una escena.

Preferir:

> La rodilla cedió cuando cargué peso.

frente a:

> La rodilla presentaba inflamación, rigidez y limitación de flexión.

## Intensidad

Cada página debe contener al menos uno de estos elementos:

- una decisión,
- una amenaza,
- una pregunta,
- una imagen potente,
- una revelación,
- un cambio emocional.

Si una página termina igual que empieza, revisar.

## Trabajo por páginas

A partir de esta versión, cada capítulo se revisará en bloques de página.

Objetivo orientativo por página: **180–320 palabras**.

Cada página debe poder:

- leerse de forma independiente durante la edición,
- escucharse cómodamente con síntesis de voz,
- corregirse sin rehacer todo el capítulo,
- tener un pequeño arco interno.

Los separadores `---` del manuscrito representan cortes naturales de página/escena hasta que el lector web tenga paginación real.

## Audio

La prosa debe sonar bien en voz alta.

Evitar:

- acumulaciones de números,
- paréntesis largos,
- frases con demasiadas subordinadas,
- repeticiones mecánicas,
- bloques técnicos sin respiración.

Leer mentalmente cada página como si fuera narrada por una sola voz.

## Anti-spoiler

Nunca anticipar en narración ni imagen algo que el protagonista aún no conoce.

Secuencia preferida:

**percibo → interpreto → dudo → pruebo → comprendo parcialmente**

## Edición capítulo a capítulo

Para cada capítulo:

1. pasar a primera persona real,
2. recortar datos secundarios,
3. eliminar repeticiones,
4. añadir personalidad donde falte,
5. reforzar tensión y sensación física,
6. dividir en páginas naturales,
7. comprobar lectura en voz alta,
8. revisar las imágenes para que coincidan con lo ya revelado.

No crear capítulos nuevos mientras esta pasada siga abierta.
