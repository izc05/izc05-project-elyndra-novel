# ELYNDRAN — MATRIZ DE IMÁGENES POR CAPÍTULO V1

Regla editorial nueva para la edición web:

- Cada capítulo debe tener **una imagen de apertura** inmediatamente bajo el título.
- Cada capítulo dispone de **dos posiciones interiores** adicionales como base.
- Se pueden añadir más imágenes solo cuando una escena narrativa concreta lo justifique.
- Los huecos no muestran placeholders rotos: permanecen ocultos hasta que exista el raster final.
- Toda imagen final debe ser hiperrealista/cinematográfica, sin texto ni interfaz incrustada.
- Texto, imagen y ritmo narrativo se revisan como un único bloque editorial.

## Convención de IDs

- Apertura: `<CAPITULO>-A.webp`
- Interior 1: `<CAPITULO>-I1.webp`
- Interior 2: `<CAPITULO>-I2.webp`

Para el Prólogo: `PROLOGO-A`, `PROLOGO-I1`, `PROLOGO-I2`.

## Criterio narrativo

La apertura debe fijar el tono del capítulo sin resumirlo ni revelar acontecimientos posteriores. Las imágenes interiores deben aparecer después de que el texto haya presentado la información visual necesaria. Si una ilustración obliga al lector a saber algo antes que Aster, se rechaza.

## Revisión continua

Para cada capítulo se trabajará en ciclo:

1. lectura del texto actual;
2. ajuste de narración, ritmo, claridad y continuidad;
3. selección de 1–3 momentos visuales;
4. generación hiperrealista;
5. QA de canon y continuidad;
6. versionado en `art/masters/`;
7. comprobación en móvil y escritorio;
8. nueva revisión conjunta texto + imagen.

El objetivo no es llenar páginas de ilustraciones, sino que cada imagen haga avanzar la experiencia del libro.
