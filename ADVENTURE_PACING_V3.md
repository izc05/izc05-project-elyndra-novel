# ELYNDRAN — ADVENTURE PACING V3

Estado: **estándar candidato de edición** para la rama `edit/adventure-pacing-top-pass`.

Objetivo: acelerar el descubrimiento de Elyndran sin perder ciencia, continuidad, supervivencia ni misterio.

## Regla principal

Cada capítulo debe hacer avanzar físicamente la aventura.

Al terminar un capítulo, al menos una de estas cosas debe haber cambiado:

- he llegado a un lugar nuevo;
- una ruta conocida ha cambiado;
- he descubierto un organismo o comportamiento nuevo;
- un recurso ha cambiado una decisión inmediata;
- una amenaza me obliga a actuar de otra forma;
- una evidencia nueva altera una hipótesis importante;
- el mapa se ha ampliado;
- tengo una nueva dirección hacia la que ir.

Si el capítulo solo confirma una medición, se comprime o se integra en otro.

## Longitud objetivo

- capítulo normal: **650–1.100 palabras**;
- capítulo de expansión grande: **1.100–1.500 palabras**;
- superar 1.500 solo si contiene varias escenas y un cambio real de región.

No alargar para cumplir una cifra.

## Ritmo de aventura

Secuencia preferida:

**NECESIDAD → SALIDA → TERRENO → DESCUBRIMIENTO → PROBLEMA → DECISIÓN → NUEVA DIRECCIÓN**

No es obligatorio usar todos los pasos, pero el movimiento debe dominar sobre el análisis.

## Regla de laboratorio

Una prueba científica solo merece desarrollo completo cuando:

1. implica riesgo físico;
2. produce una revelación importante;
3. cambia inmediatamente una conducta o una ruta.

En cualquier otro caso se resume en una o dos frases.

Evitar capítulos construidos como:

**muestra → analizador → cifras → hipótesis → registro**.

Preferir:

**descubro algo mientras avanzo → necesito decidir → utilizo una medición mínima → continúo**.

## Rutas conocidas

Un trayecto ya dominado no se vuelve a narrar paso por paso.

Puede resumirse así:

> Crucé la primera ruta y tomé la alternativa superior sin detenerme.

Solo volver a desarrollar el trayecto si algo cambia durante él.

## Protagonista

El protagonista debe seguir siendo prudente, pero no sonar como `CONTINUITY.md`.

Reducir repeticiones de:

- «no podía demostrar»;
- «no escribí»;
- «no significaba»;
- «fuente no determinada»;
- listas de descartes consecutivos.

La prudencia se demuestra también mediante conducta: no tocar, no beber, retirarse, comparar, guardar una muestra o cambiar una ruta.

## Prosa

Mantener frases breves para impacto, pero evitar cadenas telegráficas repetidas.

Por cada secuencia de frases muy cortas debe existir suficiente prosa fluida para recuperar respiración y sensación de viaje.

Usar más:

- movimiento;
- orientación espacial;
- distancia;
- clima;
- cambios de luz;
- decisiones rápidas;
- consecuencias físicas.

Usar menos:

- explicación preventiva;
- recuentos repetidos;
- procedimientos ya conocidos;
- diagnósticos sin consecuencia.

## Velocidad de mundo

ELYNDRAN debe abrirse más deprisa.

Reglas:

- máximo dos capítulos consecutivos en el mismo microsector salvo crisis;
- cada 1–2 capítulos debe aparecer una expansión material del mundo;
- cada 2–3 capítulos debe aparecer al menos uno entre nueva región, clima, ecosistema, fauna, flora, riesgo vertical o rastro de inteligencia;
- no permanecer muchos capítulos alrededor de la cápsula después de XXV;
- los misterios antiguos deben acompañar el viaje, no impedirlo.

## Misterios

Los 37 segundos, las estructuras regulares y la posible inteligencia siguen siendo hilos largos.

No hace falta investigar uno de ellos en cada capítulo.

Un misterio puede permanecer varios capítulos en segundo plano mientras el protagonista explora otro lugar.

Cuando regrese debe aportar **evidencia nueva**, no repetir una anomalía anterior.

## Final de capítulo

Preferir finales que empujen hacia adelante:

- una nueva ruta;
- una silueta lejana;
- un cambio de clima;
- una decisión;
- una pérdida que obliga a moverse;
- una pregunta concreta;
- un punto nuevo en el mapa.

Evitar terminar demasiados capítulos simplemente cerrando un archivo, apagando una pantalla o escribiendo una nota.

## Test TOP

Antes de aprobar un capítulo:

1. ¿Avanza más de lo que analiza?
2. ¿Hay al menos una imagen o situación que el lector recordará?
3. ¿Se podría cortar otro 15 % sin perder nada importante?
4. ¿El protagonista parece una persona y no un informe?
5. ¿Quiero ver inmediatamente qué hay después?

Si falla 1, 3 o 5, volver a editar.
